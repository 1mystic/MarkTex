# 🎉 Welcome to MarkTex!

**The Ultimate Markdown Editor** with LaTeX Math, Live Preview, and Annotations

---

## ✨ Key Features

### 📝 Rich Markdown Support
- **Bold**, *italic*, and ~~strikethrough~~ text
- Create lists, tables, and code blocks
- Add links and images
- Blockquotes for emphasis

### 🔢 LaTeX Math Rendering
Write beautiful equations inline like $E=mc^2$ or as display blocks:

$$
\int_{a}^{b} f(x)\,dx = F(b) - F(a)
$$

### 🎨 Live Split-View
See your changes **instantly** as you type! Drag the divider to resize panes.

### 🖊️ Annotation Mode
Click **Annotate** to draw on your compiled document with:
- ✏️ Pen tool for free-hand drawing
- ⬜ Shapes (rectangles, circles, arrows)
- 🧹 Eraser
- 💾 Export annotated PDFs

### 📤 Multi-Format Export
- Download as `.md` (Markdown)
- Export as `.html` (HTML)
- Print/Save as `.pdf` (PDF)

## 💻 Code Highlighting

### JavaScript
```javascript
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

console.log(fibonacci(10)); // Output: 55
```

### Python
```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)
```
